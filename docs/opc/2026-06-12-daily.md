### 1. Show HN：Boo —— 基于 libghostty 的 screen 风格终端复用器

Boo 是一个全新的终端复用器，基于 libghostty 构建，提供类似 GNU Screen 的操作体验，但利用了 Ghostty 的现代渲染引擎。支持多窗口、会话持久化和键盘驱动的操作流，适合在远程开发环境中作为 tmux 的轻量替代方案。

- 来源: [GitHub](https://github.com/coder/boo)

### 2. Show HN：FablePool —— 为提示词众筹，AI 公开构建产品

FablePool 是一个新颖的众筹式开发平台：用户为某个提示词（Prompt）投入资金，达到目标金额后，AI Agent 会公开地、一步步地根据提示词构建出完整产品，整个过程对社区透明。这是 AI 时代「集体创意 → 自动实现」的一次有趣尝试。

- 来源: [FablePool](https://fablepool.com)

### 3. Show HN：TunnelMind —— IP/ASN 声誉 API 与广告技术供应链审查

TunnelMind 提供了面向 IP 地址和 ASN 的声誉评分 API，覆盖广告技术供应链的安全审查场景。开发者可快速判断某个 IP 或网络是否涉及广告欺诈、恶意流量或僵尸网络行为，适合构建反欺诈和流量安全系统。

- 来源: [TunnelMind](https://tunnelmind.ai/)

### 4. Zed 发布 DeltaDB：「软件诞生在两次提交之间」

Zed 编辑器团队正式发布 DeltaDB，一个记录了 Zed 编辑器每一行代码变更全历史的新系统。团队在博客中阐述了核心理念：软件的价值不在于最终的提交快照，而在于两次提交之间的每一次增量变化。DeltaDB 可实现细粒度的时间旅行调试和协作编辑回放。
