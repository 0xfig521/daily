### 3. Ant：一个全新的 JavaScript 运行时与生态系统

- 来源: [antjs.org](https://antjs.org)

### 4. Reame：越跑越快的 CPU 推理服务器

开发者开源了 Reame，一个独特的 CPU 推理服务器，其特点是「运行越久速度越快」——通过运行时编译优化和缓存累积，持续降低后续请求的推理延迟。该项目为不想依赖 GPU 或云 API 的独立开发者提供了本地部署 AI 模型的新选择。

- 来源: [GitHub](https://github.com/swellweb/reame)
