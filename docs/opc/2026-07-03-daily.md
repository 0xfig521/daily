### 1. crustc：将整个 rustc 翻译为 C 语言

一个雄心勃勃的开源项目 crustc 完成了将 Rust 编译器（rustc）完整翻译为 C 语言的工作。这意味着开发者现在可以在没有 Rust 工具链的环境中编译 Rust 代码，也为理解 rustc 内部实现提供了更易读的 C 语言版本。对于系统编程爱好者和希望在受限环境中使用 Rust 的开发者而言，这是一个值得关注的里程碑。

### 2. modusregel：简洁美观的 Emacs 状态栏

- 来源: [Codeberg](https://codeberg.org/jjba23/modusregel)

### 3. LMDB 1.0 正式发布：轻量级内存映射数据库

Lightning Memory-Mapped Database Manager（LMDB）发布了备受期待的 1.0 版本。作为一个基于内存映射的键值存储库，LMDB 以其零配置、高并发读性能和事务安全性著称，被 OpenLDAP 和众多区块链项目采用。1.0 版本的发布标志着该历经多年打磨的底层存储引擎进入成熟稳定阶段。

- 来源: [LMDB 文档](http://www.lmdb.tech/doc/)
