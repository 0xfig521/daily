### 1. Ternlight：仅 7 MB 的浏览器端嵌入模型，WASM 运行

Ternlight 是一个体积仅 7 MB 的文本嵌入模型，可以完全在浏览器中通过 WebAssembly 运行，无需后端服务器。对于需要在客户端进行语义搜索、文本相似度计算或本地 RAG 应用的独立开发者和超级个体，它提供了一个零基础设施成本的轻量级方案。

- 来源: [Ternlight Demo](https://ternlight-demo.vercel.app/)

OpenSSH 发布了 10.4 版本，带来了多项安全改进和新特性。对于依赖 SSH 进行服务器管理和远程开发的独立开发者，建议及时升级以获取最新的安全补丁和性能优化。

- 来源: [OpenSSH](https://www.openssh.org/txt/release-10.4)

### 3. Python 3.14 编译为机器码，无需解释器

开发者 can1357 发布了 pon 项目，实现了将 Python 3.14 代码直接编译为原生机器码的运行方案，彻底摆脱了传统 CPython 解释器的性能开销。该项目目前处于早期阶段，但为 Python 性能优化提供了一条全新的技术路径，对需要高性能 Python 应用的开发者具有参考价值。

- 来源: [GitHub](https://github.com/can1357/pon)

- 来源: [CoMaps](https://www.comaps.app/)

### 5. OpenWrt One：开源硬件路由器

OpenWrt 社区推出了 OpenWrt One，一款完全开源的硬件路由器。该设备从固件到硬件设计全部开放，用户可以自由定制网络功能、安装插件并完全掌控自己的网络流量，是注重隐私和网络自主权的超级个体的理想选择。

### 6. 剪枝 RAG 上下文：仅保留答案实际需要的内容

- 来源: [Kapa.ai Blog](https://www.kapa.ai/blog/how-we-prune-rag-context)

### 7. Anthropic 研究：语言模型中的全局工作空间

Anthropic 发表了一项关于「全局工作空间」(Global Workspace) 的理论研究，探索语言模型如何实现类似人类意识的注意力广播机制。研究提出了一种新的可解释性框架，用于理解模型如何在不同推理步骤之间共享和更新信息，为构建更透明、更可控的 AI 系统提供了理论基础。

- 来源: [Anthropic Research](https://www.anthropic.com/research/global-workspace)

### 8. Januscape：KVM/x86 虚拟机客户机逃逸漏洞

- 来源: [GitHub](https://github.com/V4bel/Januscape)

### 10. M/PC – 一个拼接式操作系统

- 来源: [xxiivv wiki](https://wiki.xxiivv.com/site/m_pc.html)
