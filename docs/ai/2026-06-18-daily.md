### 1. Vercel 发布 Eve：开源 AI Agent 框架，每个 Agent 都是一个文件目录

Vercel 发布开源 AI Agent 框架 Eve，核心设计理念是将每个 Agent 的能力映射为一个文件目录——文件即能力。这种模块化的 Agent 构建方式让开发者可以像管理代码仓库一样管理 Agent 的功能集，便于版本控制、协作和复用。Eve 为 AI Agent 开发带来了一种更工程化、更可组合的新范式。
